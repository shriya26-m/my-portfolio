# Shreya Maurya — Portfolio Website

A single self-contained HTML file (no build step required).

## Run locally
Just open `index.html` in a browser, or serve it:
```
npx serve .
```

## Structure
- `index.html` — everything: markup, CSS, and JS in one file (fonts loaded from Google Fonts).

## Notes
- The contact form is validated client-side only; it is not wired to a backend/email service.
- Project "Live Demo" / "GitHub" buttons are placeholders where real URLs weren't supplied — swap the `href="#"` values in the Projects section once you have real links.
- Respects `prefers-reduced-motion` and is responsive from 360px up.
